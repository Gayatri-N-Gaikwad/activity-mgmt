# Activity Management System - Frontend

This is the frontend application for the Activity Management System, built with React.js.

## 🚀 Key Features
- **Dynamic Dashboards**: Interactive charts and statistics for faculty members using Recharts.
- **Activity Lifecycle Management**: Interface for creating activities and defining rubrics.
- **Marks Management**: Tools for bulk Excel uploads and manual mark corrections.
- **Responsive Design**: Modern, glassmorphic UI that works across devices.

## 🛠️ Tech Stack
- **React.js (v19)**: Core UI library.
- **React Router DOM**: Navigation and routing.
- **Axios**: HTTP client for API interactions.
- **Recharts**: Data visualization for performance analytics.
- **Lucide React**: Icon set.
- **Vanilla CSS**: Custom professional styling.

## 📂 Structure
- `src/components`: Shared UI components (Layout, Sidebar, Cards).
- `src/pages`: Main application pages (Dashboard, Activities, Marks).
- `src/utils`: API helper functions and utility constants.

## 🏃 Getting Started
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm start
   ```
   The app will be available at `http://localhost:3000`.
